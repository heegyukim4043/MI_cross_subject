# Contents and validation limits

This collection contains the matched development comparison, paired uncertainty
analysis and post-hoc Dreyer extension, including archived source, protocols,
predictions, scores, diagnostics and bootstrap results. Selected supporting
results, original Dreyer confirmation records, Stieger frozen-rule records,
environment specifications and current figure sources/exports are also included.

## Verified for this export

- Original source/result copies match their local source hashes.
- The frozen selection plan, record and source files were preserved unchanged.
- Python source files passed syntax parsing; this is not runtime testing.
- Current result figures and their archived supporting records are included.

## Not established

- A portable clean-clone, raw-EEG-to-results reproduction workflow.
- Complete source-record coverage of every Supplementary table.
- A comprehensive code audit, closed-loop validation or independent implementation replication.
- Physical calibration of the adopted Cho amplitude factor.
- A universally optimal regularization policy or validated reporting standard.

Archived runners and lock records retain historical path assumptions and output
locations. Preserve them as evidence; use separate portable wrappers or fresh
run directories before executing anything. Do not overwrite bundled historical
results or rerun frozen selection to refresh documentation. The original
inference script refuses to create an already existing output directory.

No raw/preprocessed EEG, manuscript/submission documents, private reviews,
historical implementation audit inventory, bytecode caches or standalone
mi-ea-checks package is included. The standalone package remains outside this
collection pending its separate review. No license is assigned by this export.

See RESULT_FILE_MAP.md for research-to-record mapping and RESEARCH_SCOPE.md for
the distinctions between pre-specified, post-hoc and exploratory evidence.
