# Contents and validation limits

Prepared locally on 2026-10-16 and anonymized for review. This file describes the upload folder,
not proof that the remote repository has already been updated.

## Included

- Initial precision-matched development comparison and paired uncertainty.
- Pre-specified Dreyer records, distinct post-hoc policy and Cho-source extensions.
- Absolute-floor sweep and development Cho-version sensitivity, with saved
  predictions, subject scores, diagnostics, joint bootstrap records and numerical
  pointwise/simultaneous bounds.
- Selected supporting gap, budget, replay, neural and frozen-rule records.
- Current result Figures 1-3 with historical plot sources/provenance.
- Input manifests and environment specifications, without raw/preprocessed EEG.

## Checks performed during this preparation

- Numerical result CSVs and NPZ arrays match their selected source bytes.
- Identifying locations and project commit references were removed from source
  and provenance copies; original frozen records remain private and unchanged.
  Historical source hashes are not new hashes for the anonymized scripts.
- Python source syntax parsing; not runtime, unit-test or full workflow testing.
- Figure metadata cleared with pixels/rendering preserved; no new plot style or estimates.
- Latest ten floor rows and two three-estimand Cho-version families are present
  with both pointwise intervals and stored simultaneous bounds.
- Root SHA256SUMS covers the supplied files, excluding itself. Historical analysis
  manifests retain original broader work-directory coverage.

These checks establish packaging consistency, not scientific certification.
Saved verification.json files describe previous analyses; they were not generated
by retraining during this release preparation.

## Not established

- Complete source-record coverage of every older Supplementary table.
- A comprehensive code/security audit, new independent EEG replication or
  closed-loop validation.
- Full neural run-to-hardware mapping or a precision/seed-matched neural policy comparison.
- Physical calibration of either Cho amplitude version.
- Universal regularizer optimality or a validated reporting standard.
- Dataset redistribution permission beyond the original dataset conditions.

Some scientific scripts retain historical hash checks and write outputs/progress records.
Do not execute them against the bundled historical result folders. Resolve paths,
input access and lock semantics in a fresh run directory. Do not rerun a frozen
selector for documentation. The old Cho conversion helper remains an uncertified
historical utility; consult CHO_AMPLITUDE_PROVENANCE.md.
