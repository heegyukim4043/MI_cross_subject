# Anonymous review copy

This distribution removes identifying local filesystem prefixes, personal account
information if present, original project commit references and image/PDF metadata.
It contains no Git history, author declarations, private review reports or raw EEG.
Third-party scholarly attribution and public dataset references are retained.

## What is unchanged

Numerical CSV results, NPZ model/prediction/bootstrap arrays, class labels and
public-dataset subject codes are unchanged. Public subject codes support paired
analysis and are not author identities; they are not names or contact details.
Dataset conditions still apply. No participants were reidentified and no identity
crosswalk is included. This is not a legal certification that public research
records are free from every possible reidentification risk.

## Source and provenance

Path constants use repository-relative locations or generic data locations.
The floor-provenance preparer reads the supplied source extraction rather than
the original private Git history. Model/statistical calculations were not changed
or rerun. Some archived scripts are still not portable execution entry points.

Identifying path prefixes in JSON copies were replaced with relative/generic
locations. Historical source hashes remain the original values, not invented
hashes or a new claim of prospective freezing. They can differ from anonymized
source bytes. Unmodified private originals retain the authoritative historical
record. Root SHA256SUMS instead verifies the files in this anonymous distribution.
Do not run archived preparation/inference/analyzer scripts against the bundled
historical outputs or describe the anonymized copies as untouched frozen files.

## Remaining anonymity boundary

File-level screening does not control the upload account, commit author/email,
repository owner, remote history or external links created during publication.
Do not include local backup/preparation folders in the anonymous upload.
Previously public matching code, figures or numerical results can still permit
content-based linkage. Removing explicit identifiers cannot guarantee that a
reviewer cannot infer the source. No claim of perfect anonymity is made.
